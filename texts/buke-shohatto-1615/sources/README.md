# Sources (not in git)

Fetched by `weft acquire buke-shohatto-1615`, which shows each license and checks the sha256 pinned
in the manifest:

- `shiseki17-p218.txt`, `shiseki17-p219.txt`, `shiseki17-p220.txt`: raw wikitext of the Japanese
  Wikisource transcription of Kaitei Shiseki shūran vol. 17 (1903), scan pages 218–220, at pinned
  revisions. The 1615 text runs from the section marker `gennarei` on page 218 to the date on page 220.
  Return marks are templates ({{レ}}, {{一}}, {{二}}, {{上}}, {{下}}); small type is {{small|…}}, and
  variant readings are ruby ({{r|base|variantィ}}).
- `murdoch1903.txt`: James Murdoch, A History of Japan, vol. 2 (1903), Internet Archive OCR text.
