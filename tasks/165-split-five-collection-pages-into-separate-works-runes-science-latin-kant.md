# Split five collection pages into separate works (runes, science-latin, kant, nietzsche, verdi-libretti) so each has its own Wikipedia article; old URLs become link pages

## Problem

Five pages bundled separate texts, so none could name one Wikipedia article (pin 164): runes (match none), science-latin (none), kant (one article stretched over two texts), nietzsche (author), verdi-libretti (author). A Weft work should be what a catalogue calls a work.

## Approach

Split by section into eleven works, line IDs and prefixes kept (kant.kpv.3 stays kant.kpv.3): runes-kylver, runes-gallehus, runes-rok, descartes-principia, newton-principia, kant-aufklaerung, kant-practical-reason, nietzsche-gay-science, nietzsche-zarathustra, verdi-traviata, verdi-otello. Each manifest carries split_from: <old>. Text-level filtering kept every comment; each filtered file was asserted equal to the old data restricted to its sections; gen/ regenerated by weft draft. The build writes a page at each old address (build.moved_pages) whose script sends old.html#<line-id> to the work holding the line; added_dates gives a split work its original's arrival date. Images: five moved to the matching work, six fetched from Commons. Found on the way: draft.py put a token's src (verbatim-check spelling) into the line text, so Nietzsche showed '.um' and Einstein's line panel showed TeX; fixed (src now feeds the check only). German lexicon stress drift filed as pin 166.
